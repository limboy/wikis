# Knowledge Creator Skill (知识点生成器)

本 Skill 旨在协助 AI Agent 将零散的信息、文章段落、用户想法或对话内容，提炼并创建为高质量、结构化的知识点卡片（Knowledge Entry）。

---

## 1. 分类判断标准

在生成知识点前，首先根据输入内容确定唯一的分类类型 `type`：

1. **`concept` (概念)**：抽象的原理、方法论、模型、定义。侧重“是什么、为什么、机制与可迁移规律”。
2. **`story` (故事)**：具象的案例、历史轶事、人物经历、故事寓言。侧重“起承转合、情境、核心启发”。
3. **`event` (事件)**：发生过的客观事实、历史节点、新闻发布、行业大事。侧重“客观事实、时间地点、历史与行业影响”。
4. **`excerpt` (摘录)**：原文片段、经典金句、精彩引言。侧重“忠实原文、触动理由、个人解读与重述”。
5. **`general` (通用/随想)**：无法明确归入上述四类的随笔、灵感碎片、未完草稿。侧重“记录初衷、自由发散、后续思考”。

---

## 2. 字段规范

生成的知识点必须符合标准的 JSON 数据格式（对应 `KnowledgeEntry` 接口）。

### 数据结构规范

```typescript
export interface KnowledgeEntry {
  id: string              // kebab-case 小写短横线连接（如 "feynman-technique"）
  title: string           // 知识点标题（简洁有力）
  type: 'concept' | 'story' | 'event' | 'excerpt' | 'general'
  oneLiner: string        // 一句话精炼总结（60字以内）
  content?: string        // 正文内容 / Markdown 格式（根据分类使用对应 Prompt 模版生成）
  source?: {              // 来源信息（若有）
    type: 'book' | 'article' | 'video' | 'podcast' | 'conversation' | 'personal'
    title: string
    author?: string
    url?: string
  }
  related: Array<{        // 关联知识点 ID 及关系类型
    targetId: string
    type: 'derived_from' | 'requires' | 'related_to' | 'contrasts_with' | 'part_of'
  }>
  tags: string[]          // 3-5 个核心标签
  createdAt: string       // ISO 8601 时间戳
  updatedAt: string       // ISO 8601 时间戳
}
```

## 3. 不同条目类型的 `content` Prompt 模版

在生成 `content` Markdown 字段时，AI Agent 必须严格根据分类选用对应的 Prompt 模版思考框架：

### 模版 1：`concept` (概念类)

```markdown
## 它是怎么回事

（请遵循费曼技巧：从最基础的地方开始，用日常生活中的类比，一步步构建理解，避免术语，除非先解释清楚。）

（至少写 3-5 段，充实而生动）

## 为什么重要

这个概念在实际中有什么用？什么时候会遇到它？

（至少写 2-3 段）

## 深入了解

技术细节、研究发现、边界情况、常见误区。

（至少写 3-5 段，这里可以用更专业的语言）
```

---

### 模版 2：`story` (故事类)

```markdown
## 故事经过

（按照“背景 - 冲突/转折 - 结局”的叙事结构生动讲述，注重细节与情节起伏。）

（至少写 3-5 段，还原真实情境与人物心理）

## 核心启发

这个故事揭示了什么道理、人性洞察或底层规律？它能给我们带来什么反思？

（至少写 2-3 段）

## 现实映射与应用

如何将故事中的智慧迁移到现代生活、工作、决策或学习场景中？

（至少写 2-3 段，结合具体现实场景）
```

---

### 模版 3：`event` (事件类)

```markdown
## 事件过程与脉络

（清晰交代事件要素：时间、地点、关键人物/组织及发展主线，梳理事件的发生经过。）

（至少写 3-5 段，客观准确、脉络清晰）

## 关键影响

该事件在当时造成了什么直接后果？引发了什么社会、行业或历史连锁反应？

（至少写 2-3 段）

## 深层驱动力与长远远见

推动事件发生的深层背景（技术、经济、文化、政策等），以及对未来的长久启示。

（至少写 2-3 段）
```

---

### 模版 4：`excerpt` (摘录类)

```markdown
## 原文摘录

> （完整、准确地引用原文片段或经典金句，附带注明出处或当时语境。）

## 记录与触动理由

为什么这段话值得被记录？它打破了什么思维惯性，或触发了怎样强烈的情感共鸣？

（至少写 2-3 段）

## 重述与延伸思考

运用“费曼学习法”，用自己的话重述这段话的核心洞见，并结合个人经验或知识体系进行拓展思考。

（至少写 2-3 段）
```

---

### 模版 5：`general` (通用/随想类)

```markdown
## 思考记录

（自由记录当前的思考片段、观察、疑问或未完成的草稿，保持原汁原味的灵感碰撞。）

（至少写 2-3 段）

## 记录初衷

当时是在什么情境或思考下产生了这一灵感？它试图解决或探索什么问题？

（至少写 1-2 段）

## 后续探究方向

提出下一步待验证的假设、需要补充查阅的资料或可扩展的延伸方向。

（至少写 1-2 段）
```

---

## 4. Agent 执行步骤

1. **输入分析**：解析用户给出的素材或主题，确定最贴切的 `type`。
2. **标识生成**：根据 `title` 的英文翻译生成简短规范的 `id`（kebab-case）。
3. **内容生成 (`content`)**：应用第 3 节中对应 `type` 的 Prompt 模版生成丰富、充实的 Markdown 文本。
4. **总结句 (`oneLiner`)**：提炼一句 60 字以内的精炼总结。
5. **链接与标签**：推断合理的 3-5 个 `tags`，若知识库中已存在相关 `id`，在 `related` 中建立有意义的双向关系（如 `requires`, `related_to` 等）。
6. **输出呈现**：
   - 展现渲染后的结构化卡片预览（Markdown 格式）。
   - 附带可直接导入系统的标准 JSON 代码块。

## 5. 示例：生成一个 `concept` 类型卡片

**输入**: “帮我生成一个关于『间隔重复』的知识点卡片。”

**输出 JSON**:
```json
{
  "id": "spaced-repetition",
  "title": "间隔重复",
  "type": "concept",
  "oneLiner": "通过不断增加复习的时间间隔，来对抗遗忘曲线并建立长期记忆的学习技巧。",
  "content": "## 它是怎么回事\n\n想象你在海滩上用沙子堆城堡...",
  "source": {
    "type": "book",
    "title": "《学习之道》",
    "author": "芭芭拉·奥克利"
  },
  "related": [
    { "targetId": "chunking", "type": "related_to" }
  ],
  "tags": ["学习方法", "记忆", "认知心理学"],
  "createdAt": "2026-07-23T20:00:00Z",
  "updatedAt": "2026-07-23T20:00:00Z"
}
```
